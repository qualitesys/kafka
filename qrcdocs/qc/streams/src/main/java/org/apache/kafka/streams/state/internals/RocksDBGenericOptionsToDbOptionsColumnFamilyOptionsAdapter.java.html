57   /**
58    * The generic {@link Options} class allows users to set all configs on one object if only default column family
59    * is used. Because we use multiple column families, we need to use {@link DBOptions} and {@link ColumnFamilyOptions}
60    * that cover a part of all options each.
61    *
62    * This class do the translation between generic {@link Options} into {@link DBOptions} and {@link ColumnFamilyOptions}.
63    */
