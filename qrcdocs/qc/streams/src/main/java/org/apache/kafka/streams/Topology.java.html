42   /**
43    * A logical representation of a {@link ProcessorTopology}.
44    * A topology is an acyclic graph of sources, processors, and sinks.
45    * A {@link SourceNode source} is a node in the graph that consumes one or more Kafka topics and forwards them to its
46    * successor nodes.
47    * A {@link Processor processor} is a node in the graph that receives input records from upstream nodes, processes the
48    * records, and optionally forwarding new records to one or all of its downstream nodes.
49    * Finally, a {@link SinkNode sink} is a node in the graph that receives records from upstream nodes and writes them to
50    * a Kafka topic.
51    * A {@code Topology} allows you to construct an acyclic graph of these nodes, and then passed into a new
52    * {@link KafkaStreams} instance that will then {@link KafkaStreams#start() begin consuming, processing, and producing
53    * records}.
54    */
