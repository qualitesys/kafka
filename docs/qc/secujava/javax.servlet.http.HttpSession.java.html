23   /**
24    *
25    * Provides a way to identify a user across more than one page
26    * request or visit to a Web site and to store information about that user.
27    *
28    * <p>The servlet container uses this interface to create a session
29    * between an HTTP client and an HTTP server. The session persists
30    * for a specified time period, across more than one connection or
31    * page request from the user. A session usually corresponds to one 
32    * user, who may visit a site many times. The server can maintain a 
33    * session in many ways such as using cookies or rewriting URLs.
34    *
35    * <p>This interface allows servlets to 
36    * <ul>
37    * <li>View and manipulate information about a session, such as
38    *     the session identifier, creation time, and last accessed time
39    * <li>Bind objects to sessions, allowing user information to persist 
40    *     across multiple user connections
41    * </ul>
42    *
43    * <p>When an application stores an object in or removes an object from a
44    * session, the session checks whether the object implements
45    * {@link HttpSessionBindingListener}. If it does, 
46    * the servlet notifies the object that it has been bound to or unbound 
47    * from the session. Notifications are sent after the binding methods complete. 
48    * For session that are invalidated or expire, notifications are sent after
49    * the session has been invalidated or expired.
50    *
51    * <p> When container migrates a session between VMs in a distributed container
52    * setting, all session attributes implementing the {@link HttpSessionActivationListener}
53    * interface are notified.
54    * 
55    * <p>A servlet should be able to handle cases in which
56    * the client does not choose to join a session, such as when cookies are
57    * intentionally turned off. Until the client joins the session,
58    * <code>isNew</code> returns <code>true</code>.  If the client chooses 
59    * not to join
60    * the session, <code>getSession</code> will return a different session
61    * on each request, and <code>isNew</code> will always return
62    * <code>true</code>.
63    *
64    * <p>Session information is scoped only to the current web application
65    * (<code>ServletContext</code>), so information stored in one context
66    * will not be directly visible in another.
67    *
68    * @author    Various
69    *
70    * @see     HttpSessionBindingListener
71    * @see     HttpSessionContext
72    */
73

240       /**
241        * Binds an object to this session, using the name specified.
